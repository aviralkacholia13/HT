# Frontend (Next.js)

This package will host the Next.js 14 application responsible for the responsive web experience, including upload flows, documents library, report review, trends, and insight cards as outlined in `docs/design.md`.

## Planned Tech Stack
- Next.js 14 (App Router) + React + TypeScript
- Tailwind CSS + Headless UI
- react-query for data fetching and caching
- react-chartjs-2 for trend visualizations

Refer to the design document for component specifications and accessibility requirements.
